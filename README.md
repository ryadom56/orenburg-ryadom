# Оренбург рядом — версия 2.0

Региональная доска объявлений на HTML/CSS/JavaScript + Supabase.

## Перед публикацией

1. В `config.js` вставьте Project URL и `sb_publishable_...` из Supabase. Не используйте `sb_secret_...`, `service_role` или любой секретный ключ в браузерном проекте.
2. В Supabase откройте SQL Editor → New query, вставьте весь текст `supabase.sql` и нажмите Run.
3. В Supabase → Authentication → URL Configuration укажите адрес опубликованного сайта в Site URL. Для локальной проверки можно временно добавить `http://localhost:5500` в Redirect URLs.
4. Загрузите файлы `index.html`, `styles.css`, `app.js`, `config.js` в корень GitHub-репозитория. `supabase.sql` и `README.md` также оставьте в репозитории.
5. Подключите репозиторий к Vercel и выполните Deploy.

## Что уже реализовано

- Регистрация и вход по email/паролю.
- Публичный просмотр объявлений из общей базы Supabase.
- Создание объявления авторизованным пользователем.
- Загрузка одного фото до 5 МБ в Supabase Storage.
- Поиск, категории, сортировка по цене и дате.
- Просмотр подробностей и удаление собственного объявления.
- Адаптивная вёрстка для телефона и компьютера.

## Важно

Это стартовая версия, а не готовый аналог Avito. Здесь пока нет чата, редактирования объявлений, модерации, восстановления пароля, жалоб и антиспама. Перед публичным запуском стоит добавить эти функции и настроить подтверждение email, лимиты и правила модерации.
